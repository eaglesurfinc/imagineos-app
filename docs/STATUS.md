## Established drawing-precision baseline

The drawing-precision follow-up is implemented in `171f43d` on `feature/drawing-precision-tablet`, based on main `0f7f6d7`. On 2026-10-19 the founder authorized merging and pushing this verified increment to main. Remote deployment success remains to be verified separately. It adds no backend migration, provider, dependency, account fixture or paid resource.

Paper removal now estimates nearby page colors and gradual lighting instead of discarding every light pixel; review includes Compare original. New regressions preserve faint graphite, pale colors and thin lines at low/default/high strength, plus a pencil line crossing uneven lighting. Similar-colored artwork, deep shadows or textured pages can still be ambiguous and need manual cleanup. Remove area uses edge-limited four-connected growth and optional tiny-gap bridging, with review controls to adjust tolerance/protection.

Select area drags a rectangular region; Lasso select traces a freehand region. New paint/shapes, fill and cleanup stay within it. Delete selection clears only those pixels, Keep only selection reviews a cutout, and Deselect exits. Undo restores edited pixels. Per-stroke selection clips survive device-draft reload. Added outlined/filled shapes are square, circle, triangle, diamond, pentagon, hexagon, star, heart and arrow.

The separate input surface handles mouse, touch and standard pen events, normalizes pressure, supports reported inverted eraser tips, cancels unfinished finger paint when a pen takes over, and prevents pinch gestures from creating strokes. Pen only turns finger contact into navigation. Connect a pen explains device-managed pairing and the input indicator confirms received pen events, not Bluetooth connection state. No vendor-specific Bluetooth integration or device enumeration is claimed. Compatibility still depends on the device/browser; physical tablet/pen pairing and mobile-browser download behavior have not been tested here.

Save to device downloads a transparent PNG of the current canvas, including offline use, without changing cloud records or adding preview guides to the image. Browser/OS settings select the destination. Failure/cancel keeps the workspace. PNG copies contain pixels; editable strokes remain in device drafts. Native desktop save-dialog code is present but native runners/mobile export remain unverified. This does not complete story/page export in Stage 7.

Drawing input, page estimation, connected regions, polygon masks, shape geometry, extraction review, download and pen setup have separate modules under `lib/features/drawing/`. Tests cover these boundaries and the real studio interactions. The required check passed formatting, static analysis, all 54 tests and release web compilation. The offline release browser check also passed; this local increment is ready for review.
