# Canvas fonts

Eight original, unmodified Google Fonts binaries are bundled with the app so the font picker does not contact a font service. Each font's SIL Open Font License is beside its binary and is included in the web assets. Names are Nunito, Patrick Hand, Balsamiq Sans, Caveat, Fredoka, Comic Neue, Lora and Baloo 2.

The pinned [Google Fonts source](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl) and individual download URLs, byte lengths and SHA-256 hashes are recorded in `manifest.json`. Tests verify the hashes and distinct rendered faces. Font size and color are app-controlled; exact text and chosen font are retained in editable device drafts. Characters outside a font's coverage may use the platform's fallback fonts.
